# Thomas Babb — Frontend Developer Portfolio

A React 19 portfolio website showcasing frontend projects and professional experience, built with Create React App and React Router.

## Live site

[Open the deployed website](https://thomas-babb-portfolio-z91p-sigma.vercel.app/)

## Local development

Install Node.js and npm:

```bash
npm install
npm start
```

Visit the local address printed by the development server (typically http://localhost:3000).

## Scripts

- `npm start` — development server
- `npm run build` — production build
- `npm test` — run configured test runner

## Notes

The website is a portfolio, not a separate hosted backend service.
